# Network Scanner App

Run:

```bash
python3 /workspace/network_scanner.py
```

Requirements:
- Python 3.8+
- PyQt5, matplotlib, pandas, nmap (CLI)

Install deps on Debian/Ubuntu:

```bash
sudo apt-get update && sudo apt-get install -y nmap python3-pyqt5 python3-pyqt5.qtwebengine python3-matplotlib python3-pandas
```

Optional: Put `Vazir.ttf` in `Fonts/` next to the script for Persian font.
